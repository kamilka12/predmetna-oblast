# Предметна область: «Бібліотека»

## 1. Опис предметної області

Розглядається діяльність мережі бібліотек. Мережа складається з кількох філій, розташованих у різних містах. У філіях працюють бібліотекарі, частина з них має керівника (старшого бібліотекаря). Читачі реєструються в бібліотеці та беруть книги додому. Кожну видачу оформлює бібліотекар: фіксуються читач, книга, дата видачі, строк повернення та фактична дата повернення. Одну книгу можуть написати кілька авторів, а один автор може мати кілька книг.

### Вимоги користувачів (запити до БД)

1. Скільки бібліотекарів працює в мережі?
2. Хто яку посаду займає і хто є керівником бібліотекаря?
3. У яких містах розташовані філії?
4. Як розподілені читачі за статтю та віком?
5. Скільки примірників кожної книги є в бібліотеці?
6. Які книги найпопулярніші, а які майже не видаються?
7. Який бібліотекар оформив найбільше видач?
8. Які книги взяв певний читач?
9. Які книги прострочено і хто з читачів їх затримує?
10. Які книги написав певний автор?

### Аналіз вимог до БД «library»

**Питання 1. Для яких типів завдань проектується БД?**
Для шести типів задач:
- Задача 1. Інформація про філії.
- Задача 2. Інформація про бібліотекарів.
- Задача 3. Інформація про читачів.
- Задача 4. Інформація про книги.
- Задача 5. Інформація про авторів.
- Задача 6. Інформація про видачі книг.

**Питання 2. Якими інформаційними об’єктами характеризуються вибрані задачі?**
- Задача 1: інформація про філії (branch).
- Задача 2: особові справи бібліотекарів (librarian).
- Задача 3: персональна інформація читача (reader).
- Задача 4: детальна інформація про книги (book).
- Задача 5: відомості про авторів (author).
- Задача 6: інформація про здійснені видачі (loan).

**Питання 3. Якою інформацією повинні бути описані дані об’єкти?**
1. Філія: назва філії, місто, вулиця, будинок.
2. Бібліотекар: ім’я, прізвище, посада, дата прийняття на роботу, філія, керівник, оклад.
3. Читач: ім’я, прізвище, стать, дата народження, номер телефону, електронна пошта, адреса.
4. Книга: назва, жанр, видавництво, рік видання, ISBN, кількість примірників.
5. Автор: ім’я, прізвище, країна.
6. Видача: бібліотекар, читач, книга, дата видачі, строк повернення, дата повернення.

**Питання 4. Яким майбутнім запитам мають задовольняти інформаційні об’єкти?**
1. Перелік читачів, які прострочили повернення книг.
2. Список книг, яких не залишилось у наявності.

## 2. Опис інформаційних об’єктів і зв’язків між ними

### Сутності та їх атрибути

Ключові атрибути (PK) стоять першими. Необов’язкові поля позначено «(не обов’язкове)».

| Сутність | Атрибути |
|---|---|
| **branch** | **branch_id**, branch_name, city, street, building_no (не обов’язкове) |
| **librarian** | **librarian_id**, first_name, last_name, position, hire_date, branch_id, manager_id (не обов’язкове), salary |
| **reader** | **reader_id**, first_name, last_name, gender, birth_date, phone_number, email, address (не обов’язкове) |
| **book** | **book_id**, title, genre, publisher, publication_year, isbn, copies_count |
| **author** | **author_id**, first_name, last_name, country |
| **loan** | **loan_id**, librarian_id, reader_id, book_id, issue_date, due_date, return_date (не обов’язкове) |

### Зв’язки між сутностями

| Назва зв’язку | Сутності | Тип | Пояснення |
|---|---|---|---|
| works_in | branch – librarian | 1 : N | У філії працює багато бібліотекарів, бібліотекар працює в одній філії |
| manages | librarian – librarian | 1 : N | Один бібліотекар керує кількома іншими; у керівника може не бути свого керівника |
| issues | librarian – loan | 1 : N | Бібліотекар оформлює багато видач |
| borrows | reader – loan | 1 : N | Читач може мати багато видач |
| is_lent | book – loan | 1 : N | Книга може видаватися багато разів |
| writes | author – book | M : N | Автор пише багато книг, у книги може бути кілька авторів |

### Обмеження цілісності

1. Значення атрибута `phone_number` — ціле додатне шестизначне число за маскою `__-__-__`.
2. Значення атрибута `gender` — один символ: `F` або `M`.
3. Значення атрибута `email` — рядок за маскою `__@__`.
4. Значення атрибута `isbn` — рядок із 13 цифр.
5. `copies_count` ≥ 0, `salary` > 0, `publication_year` — чотиризначне число, не більше поточного року.
6. `due_date` ≥ `issue_date`; `return_date`, якщо заповнене, ≥ `issue_date`.
